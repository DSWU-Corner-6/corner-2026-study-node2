git checkout : 다른 브랜치로 이동할 때 사용하는 명령어
git commit : 로컬에 기록하는 명령어
git push : 로컬에 쌓인 커밋을 깃허브에 올림
git pull : 깃허브에 올라온 것을 내 컴퓨터로 받아옴

Merge : 브랜치의 변경사항을 하나로 합치는 것
cd로 작업 폴더 들어온 상태에서 code . 입력하면 현재 경로를 바로 열 수 있음 (File - Open Folder 역할)
checkout -b : -b가 붙어야 생성 + 전환 한 번에 이루어짐
ex: git checkout -b feat/jiyun232
