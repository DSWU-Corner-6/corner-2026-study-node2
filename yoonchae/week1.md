# 💡 Node.js 스터디 1주차 정리

## 1. 오늘 겪었던 시행착오와 배운 점
* **깃허브 초대 수락의 중요성**: 
  * 과제 올리려고 하는데 자꾸 403 오류가 뜨고 막혔었다. 알고 보니 이메일로 온 조직(Organization) 초대를 먼저 수락했어야 했던 것
  앞으로는 권한 확인을 제일 먼저 해야겠다.
* **로컬에서 작업할 때 헷갈리지 말아야 할 루틴**:
  1. 작업 시작하기 전에 무조건 `git checkout main`이랑 `git pull origin main`으로 최신 상태 먼저 당겨오기!
  2. 내 폴더 안에 파일 만들어서 수정하고 꼭 저장하기 (`Ctrl + S`)
  3. `add` -> `commit` -> `push` 순서로 안전하게 올리기

## 2. 노션 & 강의 핵심 내용 요약
* **팀 레포지토리 규칙**: 
  * 내 이름으로 된 개인 폴더 안에서만 파일을 만들고 수정해야 한다. 다른 사람 폴더를 건드리면 충돌이 날 수 있으니 조심하기.
* **브랜치와 PR**:
  * 바로 메인에 올리기보다는 새 브랜치를 파서 작업한 뒤 PR(Pull Request)을 날리는 방식으로 안전하게 협업하는 법을 배웠다.
