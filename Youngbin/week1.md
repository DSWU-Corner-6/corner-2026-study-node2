' github를 통해 팀원들과 함께 프로젝트를 어떻게 진행해 나가야 하는지 알게됨.
' github 기본 설정을 하며 다양한 명령어를 익히게 됨.
  " git clone : gigub에 있는 프로젝트 전체를 내 컴퓨터(로컬)로 그대로 복제함
  " git checkout : 다른 작업공간으로 이용할떄 사용함 *작업공간을 브랜치라고 부름
  " git add : 수정한 파일을 다음 커밋에 포함시킬 목록에 올림.
  " git commit : 목록에 올라간 내용을 하나의 스냅샷으로 로컬에 메시지와 함꼐 저장
  " git push : 로컬에 쌓인 커밋들을 github에 올려 팀원들과 공유함.
  " git pull : github에 올라온 최신정보.파일을 로컬로 불러옴.
'main과 branch개념을 이해해서 코드를 어떻게 써나갈지 이해하게됨.
  "main을 짜고 가지개념으로 branch를 하나하나 만들어가면 하나의 프로젝트를 만드는데 수월할 것 같다.
' 팀원들과 함꼐 하니 각주를 쓰는 습관을 길러야겠다고 생각함.
